## Implemented flow

- A shared UTF-16 word-span selector binds observation geometry and model input.
  Windows UIA clones a text range without selecting or writing it. Prefix and
  selected-text readback must match before reported bounds can be used. Invalid,
  unsupported or unavailable geometry produces no mark; the field badge remains.
- Thin, nonactivating phrase marks open the existing explicitly requested card.
  The current source word stays marked while its card is open. New text, field,
  geometry, workspace, pipeline or dismissed-span bindings invalidate stale help.
- The phrase card leads with proposed wording and its practical effect. Apply,
  Dismiss/Skip and Full rewrite are separate actions; expanded alternatives are
  hidden for a question. Failed states hide lingering replacement/assumption
  fields and make Full rewrite the clear recovery action. No generic menus or
  replacement text are supplied by QML.
- A question can be answered inside the card. Custom typing deliberately enables
  focus for that input. Answer checking happens before the answer enters approved
  context; nonsensical or incompatible answers keep the question open.
  Accepted answers remain bound to the exact draft/field/process/workspace. If
  generation fails, returns malformed output, repeats the question, or the
  sentence audit rejects all edits, the card
  offers explicit Full rewrite and preserves the accepted answer. The normal
  revision-bound interview-record/provenance path incorporates its exact raw
  question/answer before confirming intent. Rejected answers and edited drafts
  never inherit it. The full rewrite topic now falls back to the hash-bound raw
  question for supplemental custom answers, which previously arrived with an
  empty topic. Sealed analysis questions retain precedence, and XML escaping
  remains mandatory. This does not open an interview or write the editor.
  A valid answer requests new local wording, then the existing complete-sentence
  independent audit still gates Apply. All calls share the existing deadline and
  stale/cancellation bindings. Choosing an answer never writes the source field.
- Apply feedback still requires native exact readback. Undo reverses only the
  exact applied span against the exact post-edit draft, field, process, workspace
  and pipeline. It is cleared by edits, dismissal and the seven-second feedback
  expiry; it is not a global undo stack.
- The expanded rewrite view now presents the full readable/selectable proposed
  prompt before review machinery. Compare original and Show changes are available.
  A healthy embedded meaning check is compact, with optional details. Required
  findings and approval gates are retained. Readable system sans-serif replaces
  inconsistent variable-font selection; monospace utility labels remain.

## Limits that must remain explicit

This implementation marks the current caret word when a provider supplies exact
range geometry. It is not a whole-document issue list or an extension that owns
all inline decorations. Offsets that differ under UIA character units, normalized
line endings or Unicode fail closed to badge-only help. Actual supported editors,
scrolling, multi-monitor geometry, native click routing, custom-answer focus and
Mac behavior need separate live evidence; automated QML/mock tests do not prove
universal compatibility. No Mac parity is claimed.

Synthetic model checks measure limited examples. They cannot establish that every
question is useful or that a downstream executing AI produces a better artifact.
